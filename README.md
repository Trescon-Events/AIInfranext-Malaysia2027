# AI InfraNext | Malaysia 2027

> **Where AI Infrastructure Meets Enterprise Demand**  
> 20–21 July 2027 · Kuala Lumpur, Malaysia · Organised by Trescon

Executive Next.js 16 application for **AI InfraNext Malaysia 2027**, built with React 19, TypeScript, and high-performance bespoke CSS tokens mirroring the AI InfraNext design language.

---

## Tech Stack
- **Framework:** Next.js 16 (App Router)
- **UI Library:** React 19 & TypeScript
- **Styling:** Custom High-Performance Design System (`src/app/globals.css`)
- **Assets:** Official SVG brand marks, WebP photography, and optimized MP4 background reels
- **Accessibility & Compliance:** Semantic HTML5, keyboard navigation, and PDPA 2010 dual-consent workflows

---

## Getting Started

### Prerequisites
- Node.js 18.18+ or 20+
- npm / yarn / pnpm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.

### Production Build
```bash
npm run build
npm run start
```
